# Настольное приложение на Java 17 + Swing без внешних библиотек

## Контекст и постановка задачи

Лаборатории нужен простой учёт оборудования на одном компьютере (SRS 2.1, 2.3). Курс предполагает реализацию на Java, приложение должно собираться и запускаться одной командой (REQ-INST-001). Какую платформу и UI-технологию выбрать?

## Драйверы решения

* Запуск одной командой без установки сервера и СУБД (REQ-INST-001).
* Срок релиза 29.12.2026 и компетенции команды (Java).
* Отсутствие платных компонентов (SRS 3.5.7).
* Работа без сети и без администратора.

## Рассмотренные варианты

* Java 17 + Swing (только JDK)
* Java + JavaFX
* Веб-приложение (Spring Boot + браузер)

## Итог решения

Выбранный вариант: «Java 17 + Swing», потому что это единственный вариант, который входит в состав JDK, не требует зависимостей и сервера и запускается скриптом `run.sh`.

### Последствия

* Хорошо, потому что сборка — один вызов `javac`, нет менеджера зависимостей.
* Хорошо, потому что прототип ЛР3 уже написан на Swing — код переиспользуется.
* Плохо, потому что внешний вид Swing устаревший; доступ с телефонов студентов невозможен.
* Нейтрально, потому что при переходе на веб слой сервисов можно переиспользовать (ADR-0002).

### Подтверждение

`run.sh` на чистой машине с JDK 17 компилирует проект и открывает окно входа (проверка REQ-INST-001).

## Плюсы и минусы вариантов

### Java 17 + Swing

* Хорошо, потому что входит в JDK.
* Хорошо, потому что команда знает технологию.
* Плохо, потому что ограниченные возможности оформления.

### Java + JavaFX

* Хорошо, потому что современный UI.
* Плохо, потому что начиная с JDK 11 поставляется отдельно — нужна загрузка модулей, запуск усложняется.

### Веб-приложение

* Хорошо, потому что доступ из браузера с любого устройства.
* Плохо, потому что нужен сервер, сеть кафедры и администрирование; трудоёмкость выше примерно в 2 раза — не укладывается в срок.

## Дополнительная информация

Пересмотреть, если заказчик потребует доступ студентов со своих устройств. Связано: REQ-INST-001, V-001, V-007.
