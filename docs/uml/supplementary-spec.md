# Дополнительные спецификации

Проект **«Учет лабораторного оборудования»**. Версия 1.0, 04.11.2026.

Здесь собраны требования, которые не относятся к одному прецеденту, а действуют для всей системы.

| ID | Категория | Спецификация | Источник |
| --- | --- | --- | --- |
| SS-01 | Удобство | Интерфейс полностью на русском языке | SRS 2.3 |
| SS-02 | Удобство | При отказе форма не закрывается и показывает причину, введённые данные сохраняются | REQ-FUNC-003, REQ-FUNC-006 |
| SS-03 | Удобство | Статус оборудования выделен цветом, просроченная бронь – красным | REQ-FUNC-002, REQ-FUNC-008 |
| SS-04 | Удобство | Результат действия показывается в строке состояния окна | SRS 3.3.5 |
| SS-05 | Надёжность | Данные сохраняются после каждого изменения; запись таблицы атомарна | REQ-REL-001 |
| SS-06 | Надёжность | Резервная копия – копирование каталога data/, рекомендуется раз в неделю | SDD V-007 |
| SS-07 | Надёжность | Данные прототипа переводятся в новый формат при первом запуске версии 1.0 без потерь | REQ-FUNC-008 |
| SS-08 | Производительность | Каталог из нескольких сотен записей отображается без заметной задержки | SRS 3.3.1 |
| SS-09 | Безопасность | Права проверяются в сервисах, а не только скрытием кнопок в интерфейсе | REQ-SEC-001 |
| SS-10 | Безопасность | Пароль хранится как соль и хеш PBKDF2-HMAC-SHA256 | REQ-SEC-001 |

| SS-12 | Сопровождаемость | Бизнес-правила проверяются автоматическим набором SelfTest | SRS 4 |
