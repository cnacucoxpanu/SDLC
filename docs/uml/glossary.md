# Глоссарий проекта

Проект **«Учет лабораторного оборудования»**. Версия 1.0, 04.11.2026.

| Термин | English | Определение |
| --- | --- | --- |
| Актёр | Actor | Роль, которую внешний участник играет по отношению к системе |
| Бронь | Booking | Закрепление единицы оборудования за студентом на период [с; по] включительно |
| Возврат | Return | Отметка лаборанта о том, что студент вернул выданное оборудование |
| Выдача | Issue | Отметка лаборанта о том, что студент забрал оборудование по брони |
| Действующая бронь | Actual booking | Бронь в состоянии «Активна» или «Выдана», дата окончания которой не раньше текущей даты |
| Журнал выдачи | Issue log | Вкладка лаборанта со списком броней и отметками выдачи и возврата; заменяет бумажный журнал |
| Инвентаризация | Inventory | Ежегодная сверка парка оборудования, для которой выгружаются файлы CSV |
| Инвентарный номер | Inventory number | Уникальный без учёта регистра идентификатор оборудования длиной от 1 до 20 символов |
| Каталог | Catalog | Таблица всего оборудования с поиском и фильтром по статусу |
| Лаборант | Lab assistant | Сотрудник, который ведёт каталог, статусы, выдачу и возврат |
| Оборудование | Equipment | Единица прибора или устройства лаборатории |
| Период брони | Booking period | Непрерывный интервал целых дней длиной не более 7 дней, границы входят в период |
| Прецедент | Use case | Последовательность действий системы в ответ на событие, инициированное актёром |
| Просроченная бронь | Overdue booking | Бронь в состоянии «Выдана», дата окончания которой прошла, а возврат не отмечен |
| Сервис | Service | Класс слоя labequip.service, в котором находятся бизнес-правила и проверка прав |
| Состояние брони | Booking state | Одно из значений: ACTIVE, ISSUED, RETURNED, CANCELLED |
| Статус оборудования | Equipment status | Одно из значений: FREE («Свободно»), IN_REPAIR («В ремонте») |
| Студент | Student | Пользователь, который ищет и бронирует оборудование |
| Учётная запись | User account | Логин, соль и хеш пароля, ФИО и роль пользователя; создаётся при установке |
| Хранилище | Store | Класс, который загружает таблицы TSV и атомарно сохраняет их |
| Экспорт | Export | Выгрузка каталога или журнала в файл CSV (UTF-8 с BOM, разделитель «;») |
